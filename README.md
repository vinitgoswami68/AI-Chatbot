# VINITX AI — AI Chatbot

VINITX AI is a general-purpose AI chatbot created by Vinit Goswami. It helps users with programming, studies, mathematics, technology, writing, and everyday questions.

## Features

- AI-powered question answering
- Modern, responsive chat interface
- Hindi, English, and Hinglish support
- Programming and study assistance
- Gemini API integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file in the project root and add your own Gemini API key:

   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

5. Start the backend:

   ```bash
   node server.js
   ```

6. Open `index.html` using VS Code Live Server.

## Security

- Never upload your real API key.
- Keep `.env` out of Git using `.gitignore`.
- Never expose your API key in frontend JavaScript.
